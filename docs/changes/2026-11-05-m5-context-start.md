# M5 context research — starting slice, 5 November 2026

Added a source-linked research-context adapter for existing radar SENS receipts and explicitly named issuers in retained Hermes captures. Each normalized revision retains the source and content identifiers, raw hash where supplied, publication precision, acquisition and receipt clocks, mapping basis and URL. A decision receives only context whose known publication, acquisition and receipt clocks all precede that decision. Date-only or missing clocks and later receipts remain visible as annotations; no artificial timestamp is assigned. Missing context never blocks price-only research. Current source scans have bounded limits and disclose when those limits might truncate results.

The actual local audit ran without model calls or additional strategy trials on the first retained paired M4 study for each instrument. Sasol had five explicitly issuer-linked sources and 165 reconstructed daily decision cases; BAT had 13 linked sources and 165 cases. None of those retained source revisions had all required clocks before the associated older decisions. All remain available as later or uncertain annotations, not as prior information. Tests cover before/after decision clocks, revisions, unknown clocks, explicit issuer mapping, missing-sector and broad-market fallbacks, and hash-checked read-only reports. The dashboard has a separate context-coverage panel in Backtest Lab; the running Flask server needs restarting before its new API is available. No broker settings, model budgets, pinned v1 engine, or execution paths were changed.

M5 remains open. This slice is an inventory and causal-timing join, not a trained or improved model.
