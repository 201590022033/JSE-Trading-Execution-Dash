# Sector hypothesis comparison, 4 November 2026

The existing frozen Backtest Lab replay now has a three-window sector/instrument view. It displays each strategy, including no-trade and losing strategies, and selects an instrument lead using training-window results only. Validation and holdout outcomes are not shown to the proposer. Windows were defined after this historical replay existed, so they are post-hoc and do not establish prospective validation. Shared-cash results are not standalone sector replays; trades crossing a window boundary are excluded.

`scripts/sector_family_proposal.py --run-id <hash> --sector Consumer --preview` builds the training-only context, including swing, VCP, box and pullback. Without `--preview`, the explicit runner uses the accepted local PostgreSQL ledger, the existing single daily swing-AI reservation, and a bounded choice among those families; it journals the attempt and compares all families by instrument. It does not modify a live strategy, invoke Qwen, or place orders. The new family path is prepared but has not made a model call.

`scripts/sector_swing_exploration.py --sector Consumer` evaluates three fixed retrospective swing variants over separate training, validation and holdout windows: baseline, volume strictly above 0.8 times prior average, and close above EMA50 as a looser trend gate. The last variant retains the baseline EMA20 reclaim calculation, including its original trend prerequisite. All variants use the existing shadow stop and exit mechanics, observed inputs and hypothetical cost scenarios, and are not registered production strategies. Data receipts and limitations are retained in an immutable hash-named local report. The dashboard shows each variant by selected instrument and period; these are independent per-instrument shadow outcomes, not portfolio replay returns. Funnel checked counts can differ across variants because signals are non-overlapping per instrument.

Observed Consumer results from 2024-08-20 to 2026-11-03: training/validation/holdout completed samples were baseline 8/8/1, lower-volume 10/8/3, and looser-trend 10/8/2. The holdout was only inspected after choosing these exploratory variants, so results are leads rather than prospective validation. No model trained or strategy promoted.

Cloud failure diagnosis is scheduled separately; future errors receive fixed safe categories. Existing model budgets, frozen records, execution settings and Qwen controls remain in place.
