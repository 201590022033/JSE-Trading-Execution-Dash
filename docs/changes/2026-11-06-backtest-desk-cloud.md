# Backtest desk interactive cloud advice

An explicit Ask the Desk click sends the selected role, question and frozen
run summary to the existing configured Ollama Cloud research provider and
returns its advisory report in the dashboard. The key stays server-side. A
cloud failure does not retry another model. When no cloud key is configured,
the existing idle-gated local advisor remains available. This interactive
advisory path does not reserve, change or retry the separately budgeted swing
hypothesis experiment; it does not run strategies or place orders.

Responses currently live in the open dashboard panel; they are not saved as
research records. Cloud prompts include the frozen run's compact strategy and
trade data, so the configured cloud provider receives that research context.
