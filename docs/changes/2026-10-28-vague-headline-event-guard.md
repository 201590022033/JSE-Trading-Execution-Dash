# Preserve vague news without promoting it to a specific event

The owner identified a Qwen output that treated the retained Sasol question
“Where to next?” as a future event. The host now recognizes that narrow family
of generic questions, including a price-prefixed headline, and records
`UNSPECIFIC_COMMENTARY_NEEDS_REVIEW` rather than creating a new event watch.
The source and the original model response remain available. A headline that
also names a concrete event stays reviewable; missing dates do not by themselves
disqualify a supported event. Existing saved watches and their reviews are not
rewritten.

This is a host-side correction for a known pattern, not evidence that Qwen's
general relevance accuracy improved. No new Qwen call, model fit or trading
action was made. The separate research repository adds versioned SENS detail
indexing and a governance feature family; the registered Bidvest/BAT price
comparison continues to use its frozen earlier model. R12 remains
ACTIVE/PARTIAL and P1 remains open.
