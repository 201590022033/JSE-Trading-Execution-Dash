## Mission

Build the full large minimisable visual radar matching the retained mockup, but place increasingly complete setups nearer centre; preserve text/colour status and distinguish backtested best versus least-loss, untested and no data. Select share by pointer, keyboard or touch; show top trade plan, strategy trace, volume, source/delay and context. Handoffs preselect data and never automatically execute a backtest or model call. Reuse sector, SENS, peer and momentum context with source dates; show missing data without blocking other cards. Reuse existing Ask the Desk server and explicit model selection/fallback; retain budgets and no-tool model restrictions.
