## Mission

Build separate versioned 5-minute and 30-minute strategy profiles using existing component architecture: entry, trend, momentum, volume, benchmark, stop, target, trailing and exit. Specify rules and exact baseline parameters in code and documentation; daily features use only completed available bars and intraday bars remain provisional until closed. Represent each condition as PASS/FAIL/UNKNOWN with values, threshold and provenance. Default developing signal at four of five when exactly five applicable rules are present; for other profiles use configurable ceil(80% of applicable conditions), never count unknown as a pass, and require every mandatory entry condition to pass for entry-met. A quote crossing a daily threshold remains provisional until its daily close. Replay available retained intraday history and compare with baseline including samples, costs and failure cases; never auto-promote.

2. Replays retain inputs and strategy version and show per-component reasons, sample counts and baseline comparison without claiming skill.
3. Missing optional data leaves the rest visible and never creates a confirmed false entry.
