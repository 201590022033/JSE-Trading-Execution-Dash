# Strategy Radar M12 — ViewPoint-preferred intraday source selection

Status: IMPLEMENTED LOCALLY; restarted API verified, visible overlap provenance pending — 12 November 2026.

## Context

The owner chose ViewPoint as the preferred intraday price source when its
accepted CSV evidence is available, while retaining existing-source fallback.
The existing importer preserves raw bytes and applies the operator-accepted
conventions: OHLC in ZAR cents, volume in shares, and UTC `Date` timestamps as
five-minute interval starts. This is a manual research-data path, not an
authenticated API or a guaranteed-live feed.

## Scope and boundaries

- Prefer usable, completed `IRESS_VIEWPOINT_TABLE_CSV` fields on the same
  instrument, interval, and exact bar boundaries.
- Retain other source candidates, revisions, and conflicting values. The
  selected ViewPoint value may drive research shadow despite a conflict because
  the owner explicitly selected that source preference; the conflict remains
  visible in provenance.
- Fall back per field to other usable retained sources if ViewPoint evidence is
  absent or unusable. A provisional, stale, unknown, or historical-only
  ViewPoint candidate must not displace a usable fallback. A fallback conflict
  against only unusable ViewPoint evidence may be used, with the conflict
  preserved; other unresolved source conflicts remain unknown.
- Apply the same preference to 30-minute bars derived from six same-source,
  complete ViewPoint five-minute bars. Never mix sources inside a derived bar.
- Surface the selection policy and retained conflict in evaluation, monitor
  traces, and prepared research context.
- Leave daily Zebra history and non-price context unchanged. Do not automate
  ViewPoint login, scrape the signed-in page, download files in the background,
  poll the provider, or keep the session alive.

## Acceptance criteria

1. Tests verify ViewPoint preference on overlapping fields, per-field fallback,
   unusable-ViewPoint fallback, and source-specific 30-minute derivation.
2. Conflicts and alternatives remain retained; only the explicitly preferred
   ViewPoint conflict or a fallback against exclusively unusable ViewPoint
   evidence can drive local research evaluation.
3. Strategy Radar provenance and prepared packets identify the selected source
   policy; daily-price behavior is unchanged.
4. Focused intraday, monitor, replay, API, and prepared-context regressions pass;
   the restarted dashboard exposes the same preference through its live UI.

## Current evidence and limitations

The repository already retains eight normalized MTN five-minute ViewPoint
bars. They are historical and insufficient for the current 30-minute monitor;
the other current choices have no retained five-minute rows. Manual CSV
imports are required for additional data. The freshness countdown measures
retained-data age, not whether the ViewPoint login remains valid. No provider
request, login action, model call, or order is part of M12.
