# ADR 0090: Retain generic commentary without creating an event watch

## Decision

After source citation is checked, a narrow host rule holds known generic
questions for source review instead of publishing them as individual events.
The source, model response and earlier saved watches are preserved. A phrase
that names a concrete event is not blocked by this rule, and an absent date
alone remains an admissible partial observation.

## Consequences

The known “Where to next?” false selection no longer produces a new watch
when the selected phrase is generic. The rule does not assess full-document
relevance or establish Qwen accuracy; new cases need prospective review. The
model schedule, budgets, calendar records and trading settings are unchanged.
