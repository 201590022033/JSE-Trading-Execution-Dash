# ADR 0105 · Matched hypothesis comparisons in Backtest Lab

Status: Accepted for local research implementation, 27 November 2026.

The existing exact daily runner is a file-hashed dependency of the W06 forward pilot. Keep its bytes and its single-replay interface. The comparison adapter uses the exact rule evaluator and the original cash-share runners. The selected hypothesis may add context to an entry decision. Every comparison cell uses an independent ledger with the same dates and strategy-specific sizing and fills across the family arms. Share and benchmark facts keep Zebra provenance, with eligible IRESS fields preferred when present.

Pin the current classification’s sector ETF, or STX40 for shares without a sector ETF mapping. A pinned reference avoids changes in benchmark type from one decision to another. The preview fixes the reference, evidence, range, and readiness before submission. The scan is bounded and read-only. Replay publication extends the existing immutable report metadata and uses the existing roster and saved index. Existing standalone H1 uses its original benchmark policy.

Five-minute evidence preparation uses the existing collector request directory and retained cache. An explicit request covers one completed session and the existing download path can address the latest completed session. Native export validation covers the exact symbol and interval. The daily comparison remains a daily portfolio replay. Five-minute evidence supports a separate preparation workflow while an exact intraday comparison runner remains unavailable.
