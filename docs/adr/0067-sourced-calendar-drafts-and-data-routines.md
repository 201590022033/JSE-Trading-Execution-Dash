# ADR 0067 — Cited calendar drafts and local data routines

Date: 19 October 2026. Status: accepted for exploratory research within R12; no source, model or strategy promotion.

## Decision

Extend the existing append-only research calendar, Hermes retained-news corpus and paper-record repository. Do not create another scheduler, broker login service or trading engine. The existing five-minute light clock also registers weekday 08:00 SAST import chores and source requests derived from the exact published canonical account ranking. Reads never run the ranker, download data or invoke models.

The draft lane saves an immutable, hash-bound packet before a model request. Only actually retained and timely news excerpts are eligible; the official event citation and separately labelled derived weekly context accompany them. Date-only calendar evidence and derived briefs alone cannot justify a directional proposal. Every cited passage must explicitly identify the issuer. Ollama may abstain. Host code fixes benchmark, supported measurement, expiry and three-session default; it validates exact quotes, direction and numerical trigger/failure conditions. Authenticated operator review and matching input hash are required to freeze a future expectation. The intended pre-event reference remains unresolved until separately validated as-of price selection is implemented.

Use the already installed, digest-pinned local llama3 model, with a separate owned loopback Ollama server on 11435. The existing 11434 service remains untouched. A Windows job assigned before process resume owns the server and descendants and kills them on exit/crash. Work requires ten minutes idle, at least 7 GiB free physical RAM, CPU-only generation with two threads, bounded context/output and one durable request reservation per stable event per SAST day. Returning activity or memory pressure cancels owned work; reservations and uncertain calls remain auditable. No download, cloud fallback or automatic retry spends another request.

Data readiness requires separate OST HLCV and whole real IRESS OHLCV, exact source/symbol/hash/actual acquisition identity, completed non-stale bars, and alignment with the OST Top40 benchmark. No field splicing. The red dashboard reminder clears only after current qualifying receipts. Source-definition, adjustment/action, volume and historical-availability requirements remain separate. Churn queues newly published candidates and retains departed candidates. Missing/stale/partial rankings never retire the saved membership. This does not expand the Sasol-only configured ranking universe or generalize its existing numerical IRESS routing.

Storage projections distinguish observed dataset/runtime/model bytes from five-share assumptions, incremental rows, complete daily snapshots and retained candidate histories. Proposed backup-copy counts are estimates; no retention deletion is enabled. News, documents, model files and database backup growth require separate budgeting.

## Diagnostic reconciliation

Independent agents found the new routine's datetime caller mismatch and overly permissive coverage checks; these were fixed before activation. Browser testing also exposed an older undefined variable in the Swing summary and a weekly source enabled by an explicit 10:29:57 SAST source-toggle POST. Audit/server logs rule out restart seeding; caller and original payload are unknown. The existing pause was restored with a new audit entry. Source writes now require the existing operator authority and an actual JSON boolean; failed UI changes restore the previous checkbox. Other source choices were not reset.

## Acceptance boundary

Offline domain, runner, API and actual-script UI tests plus native PostgreSQL, clock/idempotence and owned-process containment proofs validate software behavior. No actual new model generation is claimed: current RAM is below the start threshold. Source packet preparation is not an AI prediction. Outcome scoring, adjudicated relevance labels, chronological holdouts, learned weights, broad candidate onboarding, historical B5/AI admission and execution evidence remain pending. R12 remains the sole ACTIVE/PARTIAL milestone.
