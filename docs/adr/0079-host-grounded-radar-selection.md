# ADR0079 — Host-grounded radar candidate selection

27 October 2026. The v2 native positive probe returned ABSTAIN even though the
retained SARB passage explicitly said Event Date : 2026-11-19. Both v1 and v2
failures remain immutable. More source collection does not fix this failure.

Reuse the calendar's confirmed source/date records and Hermes news excerpts.
The host freezes candidate IDs, exact quotations, literal dates and direct issuer
links. Qwen selects IDs; the existing validator independently rechecks their facts.
Confirmed calendar dates appear on the radar even when model extraction fails.
An unscheduled news theme receives no invented date, price direction or issuer.
The original calendar core remains byte-identical for the paired experiment.

Register real-source-qualification-v3-selection: one matching task and two
nonmatching tasks against a retained SARB event. Both C1 and abstention are valid
schema choices in every probe; expected answers stay outside the model prompt.
Three fresh reservations test recognition only. Passing cannot reverse failed
free-text extraction or establish forecast skill. No automatic retries/reset.

The owner explicitly approved up to four local calls while using the PC: three
selection checks followed by one actual source packet. If a check fails, the
remaining calls are diagnostic only: no qualification, discovery or watch is
published. A
single persistent authorization receipt limits this campaign to four attempts,
including failures/crashes. Only this campaign can use a zero-idle override.
Routine jobs keep ten-minute idle; actual idle telemetry is retained. Keep the
installed model digest, owned server on port 11435, two CPU threads, no GPU,
3.5-GiB start / 1.5-GiB running margins, 180-second per-call deadline and local
private response archive. Existing daily discovery budget remains spent on
reservation. No broker, paid API, model fit or trading-default change.

Validate offline budget/resource boundaries, then report the actual bounded
native outcome separately. R12 stays the sole ACTIVE/PARTIAL milestone; P1
acceptance and prospective radar quality remain open.

Read-only status also exposes up to eight recent retained issuer/topic source
leads, each with its exact excerpt, actual first receipt, publication time when
known and a 48-hour expiry from that receipt. This reuses the same literal
candidate builder. These are source-navigation leads, not model predictions or
inferred SENS dates, and do not increment frozen model-watch metrics. Failed
model checks cannot suppress already ingested useful source evidence.
