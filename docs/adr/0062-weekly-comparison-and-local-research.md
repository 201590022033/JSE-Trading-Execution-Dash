# ADR 0062 — prior-week commentary and explicit local weekly research

12 October 2026. Extend ADR 0043 and retain research-only boundaries.

Current weekly text is derived context, not independent publisher evidence. Select only an earlier edition actually received before the current edition; expose its immutable watchlist and pass bounded context to the existing two-hypothesis Ollama scan. Independent article references and publisher/duplicate checks retain exclusive control over the maximum 0.05 attention boost. Trading weight stays zero. Record the prior brief identity with the scan and validate its receipt relationship on ingress.

Authenticated operator audit commentary is stored separately, bounded to 15,000 characters and keyed by brief/content. It cannot overwrite the source or confer verification. The dashboard escapes all content. There is no historical trigger rewrite or retrospective success claim.

The remote script keeps mandatory HTTPS. Explicit `--local` pins the destination to `127.0.0.1:5000` and retains bearer authentication, independent of arbitrary configured URLs. This enables local research while Railway is unavailable. No credentials are copied to files or the browser.

Existing weekly task delivery remains manual import. No duplicate automation, strategy promotion or LLM training is implied. Source evidence and prospective outcomes are separate. Cloud upload waits for the owner to resolve the subscription outage.

## Measured CPU recovery

An initial 480-second call timed out: the installed 8B CPU model processed 4,940 prompt tokens at about 17 tokens/second, then generated at about 1.5 tokens/second. Loading took 50.6 seconds. There was no out-of-memory error. Independent diagnosis and review approved one retry with explicit excerpts, at most eight source articles, a 5,500-character combined prompt/schema ceiling (an estimate, not an exact token bound), and a hard 400-token output ceiling. Timeout remains 480 seconds. The receipt and dashboard disclose selected coverage. Original documents and failed receipts remain retained. Schema and independent validation use the same selected real references. Truncated or invalid output earns no boost; failure stops further retries in this task.

The local dashboard process must receive the matching private upload token in its environment; `--local` does not disable authentication. No credentials are embedded in the launcher or CLI arguments.
