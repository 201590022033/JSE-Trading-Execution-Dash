# ADR 0098: Versioned intraday shadow profiles

Status: accepted locally, 6 November 2026.

Define `intraday_5m_research_v1` and `intraday_30m_research_v1`, each version 1.0.0, as separate research profiles. They do not alter the existing daily registry, signal weights, order handling or paper strategy. They evaluate four consecutive completed bars from the same reviewed JSE session, using only source evidence received by the evaluation time. A missing or provisional bar, unreviewed/closed session or stale last bar produces UNKNOWN. Current evaluation never turns historical, stale, unknown or conflicting field evidence into a confirmed rule. A historical replay can use actual-as-of historical evidence only in explicit shadow mode; its output is never a current signal.

The five applicable entry components are: mandatory entry = latest close above prior high (and optional configured daily close gate); mandatory trend = latest close above mean of prior three closes; mandatory momentum = latest close above prior close; optional volume = latest volume >= 1.2 times the prior three-bar mean; optional benchmark = three-interval stock return above aligned benchmark return. Developing uses ceil(0.8 × applicable), so 4/5; UNKNOWN is not a pass. ENTRY_MET requires all mandatory rules, while optional unknowns remain visible. Each trace has state, value, threshold and field/source/receipt lineage. A daily gate requires an actual completed, non-conflicting source observation and receipt after the reviewed daily close.

Research geometry assumes a stop 2% below the completed reference close, target 2R, no trailing, and exit at three bars or target/stop. These are assumptions, not verified broker prices. The current replay is a descriptive first-eligible-next-bar open-to-close comparison after actual receipt, with identical candidate/baseline outcome definitions and a disclosed round-trip cost assumption. It does not simulate the profile stop, target or three-bar exit, actual fills, liquidity, or P&L; it makes no promotion or skill claim. The report freezes profile/configuration, input records, as-of snapshots, timestamps, exclusions and hashes.

Thirty-minute evaluation may use direct records or six complete aligned five-minute observations from the same source. Derivations preserve source input records and receipt-versioned revisions; the derived interval-end clock is explicitly identified as derived. The local dashboard offers on-demand shadow checks and explicit research replay only. No polling, provider, model, broker or order action is added.
