# ADR 0065 — Local Hermes evidence foundation

Date: 16 October 2026. Status: accepted for preparatory R12 research.

The owner requested local Hermes implementation after the fresh local migration. Independent investigation confirmed that legacy weekly scans lose untriggered article inputs and that operator commentary is not an independent relevance label. Independent acceptance review reconciled the source and persistence findings before native diagnostic activation. R12 remains the sole ACTIVE milestone; implementation does not certify its missing relevance evidence.

Reuse the existing ExperimentRepository domain contract through a durable adapter over the existing immutable paper record store. An explicitly created research-only namespace account has no cash balance, positions or execution authority. Typed allowlisted JSON, content hashes, exact contract replay and a PostgreSQL advisory transaction lock protect immutable lineage. Actual storage receipt is separate from scientific timestamps. No schema migration or startup initialization is needed; bounded capacity fails closed.

The explicit local diagnostic retains excerpt hashes and actual source receipts, enumerates article/instrument review pairs, records a DRAFT experiment and characterizes only the frozen issuer guard when human-asserted labels exist. Exports blind first-pass reviewers to previous model selections and baseline predictions. Conflicting labels require adjudication instead of replacement. Human assertions do not establish verified independence. Uncertain labels abstain. No candidate treatment is implemented or measured by this slice.

Future weekly ingress retains all normalized supplied excerpts, including zero-case scans, with supplied/retained counts and normalization limits. This is a bounded supplied corpus, not all fetched/web news: prior CPU selection, the 20-article normalization limit, invalid inputs and excerpt truncation remain explicit. Legacy records are unchanged; missing prior denominators cannot be recovered by assertion. Hashes cover retained normalized excerpt identity, not raw publisher bytes.

No model calls, new scheduled supervisor, weight application, source unpause or B5/AI/execution promotion follows. Existing idle worker/backup controls remain. Grouped chronological holdout, independent adjudicated labels, broad prospective denominator and an actual single-change candidate are required before a later learning/evaluation slice. The Swing supervisor remains proposed.
