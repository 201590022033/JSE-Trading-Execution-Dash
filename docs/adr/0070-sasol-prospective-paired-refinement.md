# ADR 0070 — Operational Sasol paired shadow refinement

20 October 2026. R12 research continuation, no historical admission or promotion.

Freeze the existing1.1 feature/1.2 execution baseline and one stricter volume gate (>1.2 versus>1.0), with all other rules identical. Reuse validated whole IRESS Sasol/OST Top40 inputs, immutable source receipts, technical snapshots and the conservative daily shadow simulator. Observe only newest aligned capture endpoints after registration; imported history supplies feature context, never retrospective experimental outcomes. No news labels or historical B5 admission are required for this explicitly unverified prospective numerical lane.

One paired episode may be active at a time. Record no-setup and busy days as controls, simulate each arm only on subsequently captured endpoints, and keep actual receipt times distinct from daily-close proxies. Entry must meet the deadline using actual receipt, including when old session proxies appear timely. Costs10/25/50bps are assumptions, not OST fees. Freeze executable implementation hashes and whole consumed feature dependencies (share integer OHLCV, benchmark close cents). Detect later overlapping context and endpoint revisions; exclude affected comparisons without rewriting observations, entries or outcomes. Idempotent light-clock ticks process imports and record reviews without model/provider/trading calls.

Operational completion means definition → daily controls → paired shadow outcomes → comparative review and next-test request are connected, including honest insufficient-evidence states. Empirical improvement is separate: predeclare20 informative non-overlapping paired episodes as a review gate, not a statistical-power guarantee. No-setup days cannot satisfy it. Candidate advantage across cost scenarios and no worse unit-notional drawdown can request independent review only; rejection/mixed evidence keeps the baseline. No automatic parameter application, canonical rule mutation or brokerage is permitted.

Results are sequential exploratory sampled-path comparisons. Missing exchange sessions may hide stop/target touches; the horizon counts observed endpoints, not verified consecutive exchange days. A zero-trade candidate is disclosed as such. Twenty informative pairs are an independent-review threshold, not a one-shot significance test; repeated review cannot prove an edge. A proposed RSI ceiling test is saved only for a new future experiment, never applied to the ongoing pair.

The coordinator reuses the paper-record repository, existing feature/policy/simulator implementations and light clock. It intentionally does not enable the historical AI proposer: that path has a different historical-admission contract. Definition, episodes, actual endpoint observations, progress, terminal results, revisions and reviews form one versioned append-only ledger in its own paper account. Reads do not tick. No extra worker or Ollama task is introduced.
