# ADR0082 — Preserve a four-cell request/width diagnosis

27 October 2026. The first corrected real-source screen abstained on eight
candidates after narrow event checks passed. The owner authorized a four-call
foreground comparison. A separate append-only contract freezes the retained
packet, two-candidate subset, broad and explicit requests, assistant expectations,
source clocks, existing calendar title provenance, prompts, schemas and model
digest before generation. Both boolean values remain permitted. Cases are spent
on reservation and the shared lock/owned local runner is reused. Failures and
interruptions cannot be retried automatically. The daily discovery reservation,
earlier raw responses and operational hold are not reset.

The broad request passed on two items and abstained on eight. The explicit Sasol
AGM request passed both widths, including unrelated-issuer and same-issuer /
wrong-event controls. This is an interaction observed on one retained packet,
not broad source accuracy or a proven causal mechanism. The first pair's broad
assessment contains only positives. No watch, training label, forecast or hold
clearance is produced by the diagnosis.

The diagnosis module is separate from the production worker because it must
compare four frozen research cells without altering the one-call daily worker's
contract. It reuses the existing radar persistence, source checks, prompt/schema,
model profile, owned runner and shared lock; it does not duplicate inference or
source acquisition. Future small-batch production work follows the separately
documented plan and requires full merged-packet validation before any clearance.
