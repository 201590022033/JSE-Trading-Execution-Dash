# ADR 0069 — Evidence-bound learning coordinator

Date: 20 October 2026. Status: implementation within R12, research only.

Extend the existing retained-news repository, calendar clock, experiment records and owned Ollama runner. Add a deterministic news coordinator which assembles the frozen training cohort, independently adjudicated training evidence, recurring errors, retrieved lessons and explicit next-stage requirements. Do not inspect held-out passages or labels to adapt a candidate. Keep the registered21–28October protocol, acquisition limits, source pause and all frozen decisions unchanged.

Lesson records carry original evidence IDs/hashes and scope. Human review assertions are not verified identities; an LLM opinion never supplies reference truth. A diagnostic/proposal request is not an executable candidate or an accepted strategy. Reuse the existing evaluation-plan readiness path; any changed classifier needs an explicit frozen configuration and separately registered new future cohort before comparison. Do not repeatedly consume an existing holdout to select changes.

The existing light clock may make an idempotent evidence-triggered/weekly coordinator receipt, without providers, models or trading. Public status reads never perform this work. Keep news relevance and Swing financial scorecards separate. Future heavy candidate tests retain global locking, idle/memory cancellation and bounded durable reservations. The older Swing proposal validator must also enforce exactly one changed baseline parameter; it does not reopen historical source admission.

Provide an explicit one-shot small-model source-packet trial using the existing owned process and actual citation validation. Its profile is isolated from production, digest-pinned, CPU-only/two threads, idle-gated and durable before generation. A syntax/citation-valid response is a draft or abstention, not a proof of semantic accuracy, a human label, model training or permission to trade. Failed attempts remain auditable and do not retry automatically.
