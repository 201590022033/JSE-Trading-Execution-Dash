## Implemented operation

The existing five-minute light calendar clock now calls an idempotent coordinator. One immutable review is retained per SAST week and actual frozen-training evidence hash. Newly adjudicated training evidence may create a successor review during the same week; unchanged evidence does not. A missed weekly check is recorded when the PC actually resumes, never backdated. Dashboard refresh only reads saved records; the protected **Record learning review** button explicitly requests the deterministic review.

Each review assembles the plan's frozen training cohort, independently asserted human reviews and separate adjudications, recurring direct-link errors, indirect exposure gaps and a next-stage request. It never reads heldout examples or labels for adaptation, evaluates a holdout automatically, downloads more news, calls a model, unpauses a source or changes a trading weight. This preserves the21–28October baseline protocol and four bounded acquisition attempts. Future collection remains21/23/26/27October08:00SAST; additional collection still requires capacity review.

Training lessons bind the complete adjudication, referenced human reviews, immutable example and frozen corpus identity. Retrieval revalidates origins, identity separation, decisions, receipt chronology and resolution, recomputes the finding and verifies its full evidence hash. Foreign-issuer lessons cannot enter a share's source packet. Training lessons may accompany new cited drafts, explicitly labelled as prior review context; they are excluded from the news citation allowlist. They are not causal market rules or verified reviewer credentials.

A classifier-change request needs the declared minimum training targets, the declared minimum distinct event groups, and both positive and negative non-uncertain classes. Repeating one article across shares does not supply independent events. An indirect exposure label is a separate mapping requirement, not proof the direct-name guard is broken. A single-class or sparse set stays WAITING. If there is no supported deficiency, the coordinator does not force a change.

News and Swing acceptance are separate. News review tracks applicability, false links, precision/recall and abstention/coverage. Swing additionally needs source admission, cost sensitivity, portfolio drawdown, exposures and independent forward outcomes. Existing minimum counts are evidence gates, not statistical-power guarantees. Proposal requests name one changed component and require an explicit reviewed configuration/hash, separately preregistered new future cohort, paired baseline comparison and independent acceptance. **No executable changed classifier or automatic candidate optimizer has been registered by this slice.** The current baseline cohort cannot become an unseen test for a candidate selected using its results.

The older Swing validator now rejects simultaneous changes to multiple baseline parameters. Its corresponding prompt asks for exactly one change. This aligns the legacy proposal path with the existing scientific registry's single-treatment contract; it does not reopen its blocked OST historical evaluation.
